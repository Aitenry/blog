## 个人 AI 工作台

RytenBench 是一款专为个人用户设计的 AI 工作台，集成了日常工作和学习中常用的各种功能，旨在提高个人效率和生产力。它使用
Electron、React 和 TypeScript 构建为跨平台桌面应用程序，以 PGLite（PostgreSQL in WebAssembly）作为本地数据库，并深度集成
LangChain + LangGraph + deepagents 打造智能 AI 助手。

### 技术栈

| 技术               | 说明                               |
|------------------|----------------------------------|
| Electron         | 桌面应用框架                           |
| electron-vite    | 新一代 Electron 构建工具                |
| React 19         | 前端框架                             |
| TypeScript       | 开发语言                             |
| Ant Design 6     | UI 组件库                           |
| Tailwind CSS 4   | CSS 框架                           |
| Tailwind CSS 4   | CSS 框架                           |
| LangChain        | AI 框架                            |
| LangGraph        | AI 工作流编排                         |
| deepagents       | 子代理编排                            |
| ECharts 6        | 数据可视化（知识图谱）                      |
| electron-store   | 配置持久化                            |
| electron-updater | 应用自动更新                           |
| electron-builder | 应用打包                             |
| PGLite           | 本地数据库（PostgreSQL in WebAssembly） |

### 核心特性

| 特性             | 说明                                                                                                                                                       |
|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|
| Home Canvas    | 可视化桌面画布，文档、Wiki、待办以交互式节点展示，节点位置跨会话持久化                                                                                                                    |
| 文档管理           | Markdown 文档创建编辑、图片嵌入、全文搜索，支持 TXT/MD/DOCX/HTML 导入与 Markdown 导出                                                                                            |
| Wiki           | 层级目录树组织文档，文档间多对多关联，支持归档管理                                                                                                                                |
| 知识图谱           | 基于 LLM 自动抽取实体与关系、实体合并与二次扫描（gleaning），ECharts 6 可视化                                                                                                       |
| AI 聊天助手        | 流式响应、深度思考（reasoning）展示、工具调用、子代理编排，支持工作区级聊天历史与技能集成                                                                                                        |
| Agent 系统       | 按工作区配置子代理（自定义提示词与工具选择），主代理支持可配置工具与技能                                                                                                                     |
| 技能系统           | 从本地目录加载自定义技能，可在会话中启用/停用技能                                                                                                                                |
| 多 Provider LLM | 支持 OpenAI、Anthropic、DeepSeek、Gemini、Vertex AI、Mistral、Ollama、OpenRouter、xAI、Bedrock、Cloudflare Workers AI 及任意 OpenAI 兼容端点，API Key 使用 AES-256-GCM 加密并绑定本机 |
| 计划             | 甘特图任务管理、层级任务树、任务依赖、优先级与完成状态跟踪                                                                                                                            |
| 天气             | Open-Meteo 实时天气与多日预报，electron-store 离线缓存                                                                                                                 |
| 音乐播放器          | 文件夹式歌单、播放控制、喜欢/最近播放、侧边栏迷你播放器，自动提取音频元数据与封面                                                                                                                |
| 主题切换           | 亮色/暗色/自动主题，自动模式按时间段切换（6:00 ~ 18:00）                                                                                                                      |
| 自定义窗口框架        | 无边框窗口，含标题栏、侧边栏导航、底栏与右栏面板                                                                                                                                 |
| 锁屏             | MD5 哈希密码锁屏，按 Esc 触发，保护隐私                                                                                                                                 |
| 自动更新           | 基于 electron-updater 的应用自动更新                                                                                                                              |
| 现代 UI          | Ant Design 6 + Tailwind CSS 4 打造的简洁响应式界面                                                                                                                 |
| 跨平台            | 原生运行在 Windows、macOS 和 Linux 上                                                                                                                            |
